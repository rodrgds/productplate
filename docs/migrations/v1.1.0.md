# Product Plate v1.1 migration

- Update the local CLI before checking managed upgrades: `bun add --dev create-product-plate@latest`.
- Run `bunx product-plate upgrade --check` and review the profile-specific plan before applying it.
- Configure `TRANSACTIONAL_EMAIL_FROM` and the profile's required Cloudflare and Convex runtime values before enabling deployment.
- Keep `.product-plate/managed-files.json` tracked. Upgrade backups and transaction staging remain local and ignored by Git.
- Recheck product-specific legal text, the production URL, support details, and provider credentials before strict launch verification.
